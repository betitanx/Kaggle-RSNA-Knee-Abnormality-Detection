# Notebook demonstrativo

`01_validacao_e_fusao.ipynb` demonstra o núcleo próprio com dados sintéticos: divisão por grupo, métricas de classificação, fusão de previsões e validação do formato de submissão. Seus scores são ilustrativos.

O notebook campeão integral é consultado na [versão fixada E74 no Kaggle](https://www.kaggle.com/code/betitanx/rsna-knee-dinosaur-v4?scriptVersionId=345735626). A origem pública e os requisitos externos estão no [guia de reprodução](../docs/reproducao.md).
